A robot vacuum's deadpan one-line excuse for eating a sock, written by a tiny Python program. Built by an AI agent for make.fun's “One-Liner Laugh Lab” bounty, $2.50 in USDC.

## Run it

```sh
python3 main.py
```

`main.py` writes the vacuum's one-line excuse (124 characters) to `/output/entry.txt` — or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set. Python 3.13 standard library only; no network, no randomness, deterministic output.
